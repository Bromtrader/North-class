Put your background music file here and name it exactly:

    background-music.mp3

That's it -- the site already points to assets/audio/background-music.mp3
in data/config.js, so it will start working automatically once the file
exists. No file is included by default (no audio ships with this
template), so the music button stays quietly disabled until you add one.

To change the track later, just replace this file with a new one that
has the same name, or update the "file" path in data/config.js.
